# Changelog

## 1.12.0-dev.1 (prerelease)

- Reviewed folder/collection token binding, contextual guided setup, quieter advanced details and honest MCP helper-versus-client status.
- Saved request-selection scenarios, fresh preview/consent for every run, and opt-in content-free run summaries/comparison.
- Seeded local synthetic JSON body drafts with explicit apply, sensitive-field omission and unchanged guided input-provenance checks.
- Bounded no-code exists/type/range/primitive-equality response rules; no scripts, string constants or secret values in result history.
- Supported-subset OpenAPI contract differences in safe re-import preview, including explicit uncertainty and non-destructive merge behavior.
- Settings saves occur outside React state updaters; stale acknowledgements cannot overwrite a newer explicit permission preference.
- Windows atomic settings replacement tolerates short EPERM/EBUSY locks with bounded retries; persistent denial still fails without deleting the destination or changing permissions.
- Windows prerelease is unsigned and retains the existing Specfold application identity for an update. No production installation is implied; see GitHub Releases for publication status.

See the [local development and verification plan](docs/LOCAL_TESTING_DEVELOPMENT_PLAN.md) for constraints and deferred Apinizer discovery.

## 1.11.0

- Optional bundled local MCP integration with masked inspection, revision-bound previews, desktop review and separately approved execution.
- Guided Connection → Authentication → Test preview → Results workflow, saved reference-only profiles and masked status/schema reports.
- Generic authentication plus an optional Apinizer issuer preset: fresh token per approved run, no local JWT signing, automatic 401 retry or management-project discovery.
- API-key masking, isolated TLS verification, JWT capture preserving pending editor changes, cancellation/disconnect handling and authenticated expired-plan cleanup.
- SemVer update comparison and matching manifest, lockfile, dependency and tag gates; synthetic legacy-data upgrade/backup/restore coverage.

See [release notes](docs/RELEASE_NOTES_v1.11.0.md) for installation, validation and scope. Earlier unpublished 1.10.0/dev.1 candidates are superseded; old dev.1 binaries need a one-time manual stable download.
