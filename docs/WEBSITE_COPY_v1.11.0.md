## English

Specfold 1.11 brings local MCP support and a guided API test workflow. Connect an OpenAPI file, URL or saved collection; configure authentication; review documented test inputs and destinations; then inspect status/schema results and export a masked report.

Choose generic bearer, basic or API-key authentication, or the optional Apinizer issuer preset. Credentials stay in encrypted desktop environment variables. Agents use saved profiles and native human approval; calls that may change data require explicit selection. Unsupported or missing inputs are skipped or blocked with reasons.

Apinizer management-project discovery is not included. The preset uses a configured issuer contract and does not sign JWTs. Schema validation is a supported subset, redaction is heuristic, and canceling cannot undo server-side work. Review exported API data before sharing it.

Download label after publication: **Download Specfold 1.11.0**. Populate Windows/macOS/Linux links only with verified published assets; disclose unsigned/notarization status where applicable.

## Turkish

Specfold 1.11, yerel MCP desteği ve adım adım API test akışı sunar. OpenAPI dosyası, URL veya kayıtlı koleksiyonla bağlantıyı tanımlayın; kimlik doğrulamayı ayarlayın; belgelenmiş test girdilerini ve hedefleri gözden geçirin; durum/şema sonuçlarını inceleyip maskelenmiş raporu dışa aktarın.

Genel bearer, basic veya API anahtarı doğrulamasını ya da isteğe bağlı Apinizer issuer ayarını seçin. Kimlik bilgileri masaüstünde şifreli ortam değişkenlerinde tutulur. Ajanlar kayıtlı profilleri ve kullanıcı onayını kullanır; veri değiştirebilecek çağrılar açık seçim gerektirir. Eksik veya desteklenmeyen girdiler gerekçeleriyle atlanır ya da engellenir.

Apinizer yönetim hesabıyla proje keşfi bu sürümün kapsamında değildir. Ayar, tanımladığınız issuer sözleşmesiyle token ister; JWT imzalamaz. Şema doğrulaması sınırlı bir alt kümedir; maskeleme sezgiseldir ve iptal sunucuda gerçekleşmiş işlemleri geri alamaz. Paylaşmadan önce dışa aktarılan API verisini inceleyin.
